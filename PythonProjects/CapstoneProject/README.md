# Student Management System

A CLI-based Student Management System built with Python.

This is my capstone Python project, created to bring together
the concepts I learned throughout my previous Python projects.

## Features

- Add student records
- Delete student records
- Update student details
- Display all students
- Search students by ID
- Search students by name
- Add and update subject marks
- Calculate percentage
- Calculate GPA
- Calculate grades
- Determine pass/fail status
- Generate individual student reports
- Generate class performance reports
- Generate subject-wise reports
- Store data persistently using JSON

## Concepts Used

- Python OOP
- Classes and objects
- Instance methods
- Static methods
- Lists
- Dictionaries
- Loops
- Conditional statements
- Functions
- Exception handling
- File handling
- JSON
- CRUD operations
- Data aggregation
- CLI application design
